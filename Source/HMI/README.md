# Source/HMI/

Code lié aux **interfaces homme-machine**.

## Périmètre
- Rendu à l'écran (pipeline DirectX, sprites, couches).
- Menus, HUD, écrans (titre, pause, fin de niveau).
- Gestion des entrées utilisateur (clavier, souris, manette).
- Retour visuel et sonore côté présentation.

Ce dossier dépend de `../Core/` pour l'état à afficher, mais ne contient pas la logique de jeu elle-même.

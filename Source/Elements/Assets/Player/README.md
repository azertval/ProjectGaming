# Elements/Assets/Player/

Spritesheet du personnage (`LOT-48`) : voir la section « `Player/` — spritesheet du personnage »
du `README.md` parent pour le format attendu (`player.png` + `player.anim.json`), l'ancrage
centre-bas et la liste des clips.

Aucun fichier n'est livré ici : le jeu retombe automatiquement sur la silhouette procédurale
historique (`atlas.png`) tant qu'aucune spritesheet n'est déposée — un artiste peut la remplacer
sans toucher au code, exactement comme pour `Skins/`/`Backgrounds/`/`Objects/`.

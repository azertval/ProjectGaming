# Source/Elements/

**Assets et éléments statiques** du jeu.

## Périmètre
- Sprites, tilesets, textures.
- Sons et musiques.
- Définitions de niveaux / cartes.
- Polices, données statiques et autres ressources.

Ces éléments sont consommés par `../Core/` (données de niveau) et `../HMI/` (rendu).

> Note : les assets binaires volumineux peuvent être gérés à part (Git LFS) selon leur taille.

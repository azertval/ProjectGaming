TEST ( PixelArtScaleTest ,
FacteurMonotoneEnHauteur  )

Le facteur ne décroît jamais quand la fenêtre grandit.

C'est ce qui rend le redimensionnement prévisible : agrandir la fenêtre ne peut pas rapetisser l'interface. Cas de test : Le facteur croit de facon monotone avec la hauteur de fenetre.
Categorie : Unitaire · Echelle pixel art
Criticite : Majeur
Etapes :
1. Parcourir les hauteurs de 0 a 2400 par pas de 1.
2. Comparer chaque facteur au precedent.
Resultat attendu : Le facteur ne diminue jamais.

◆ TEST() [2/4]

TEST ( PixelArtScaleTest ,
FacteurToujoursBorneEntreUnEtLePlafond  )

Le facteur est toujours un entier d'au moins 1 et n'excède jamais le plafond, pour n'importe quelle hauteur — y compris absurde (nulle, négative, gigantesque).

Un facteur nul ferait disparaître l'interface ; un facteur non borné remplirait l'écran de trois entrées de menu. Cas de test : Le facteur reste entier, superieur a 1 et borne par le plafond.
Categorie : Unitaire · Echelle pixel art
Criticite : Critique
Etapes :
1. Demander le facteur pour des hauteurs allant du negatif au tres grand.
Resultat attendu : Chaque resultat est compris entre 1 et PIXEL_ART_MAX_SCALE inclus.

◆ TEST() [3/4]

TEST ( PixelArtScaleTest ,
HauteursCourantesDonnentLesFacteursAnnonces  )

Les trois hauteurs de fenêtre courantes tombent sur les facteurs annoncés dans les maquettes : 720p à ×2, 1080p à ×3, et 1440p reste à ×3 (plafond).

Ce test fige la promesse faite au level designer, pas seulement la formule. Cas de test : Les hauteurs d'ecran courantes donnent les facteurs annonces.
Categorie : Unitaire · Echelle pixel art
Criticite : Majeur
Etapes :
1. Demander le facteur pour 360, 720, 1080 et 1440 pixels logiques.
Resultat attendu : Respectivement 1, 2, 3 et 3.

◆ TEST() [4/4]

TEST ( PixelArtScaleTest ,
LeSeuilEstAtteintParDefautJamaisParArrondi  )

Une hauteur juste sous un seuil garde le facteur inférieur : la maquette doit tenir ENTIÈREMENT dans la fenêtre.

Arrondir plutôt que tronquer ferait passer une fenêtre de 700 px à l'échelle 2, pour laquelle il manque 20 px — la dernière entrée du menu passerait sous le bord. Cas de test : Une hauteur juste insuffisante ne declenche pas le facteur superieur.
Categorie : Unitaire · Echelle pixel art
Criticite : Critique
Etapes :
1. Demander le facteur juste avant et juste apres chaque multiple de la hauteur de base.
Resultat attendu : Le facteur ne monte qu'a partir du multiple exact, jamais avant.

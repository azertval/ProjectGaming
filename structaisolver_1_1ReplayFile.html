Detailed Description

Un fichier de rejeu : séquence déterministe de core::PlayerInput rejouable en jeu sans aucune inférence live, avec ses métadonnées d'entraînement.

Format JSON (schéma) :

{
"formatVersion": 2,
"levelPath": "demo-deplacement.json",
"levelFingerprint": 0,
"algorithmName": "evolutionnaire",
"exportedAtIso8601": "2026-08-23T12:00:00Z",
"seed": 42,
"finalReward": 1.0,
"totalDurationSeconds": 1.5,
"algorithmId": "evo",
"steps": [
{"moveX": 1.0, "jumpPressed": false, "jumpHeld": false, "moveY": 0.0,
"dashPressed": false, "interactPressed": false, "interactHeld": false,
"interactReleased": false},
...
]
}

Detailed Description

Page du QStackedWidget (comme MainMenu/CreditsScreen), pas un recouvrement.

Possède le TrainingWorker et son QThread : créés à la demande (« Lancer l'entraînement »), jamais avant ; arrêtés proprement (requestStop puis wait()) avant toute destruction.

Nombre maximal de lignes conservées dans le tableau de statistiques.

L'historique complet vit dans le stats.csv du run ; ce tableau montre ce qui vient de se passer. Sans plafond, un run de plusieurs milliers d'épisodes alloue autant de fois huit cellules que personne ne fera jamais défiler.

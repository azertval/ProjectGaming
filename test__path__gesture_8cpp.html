Cas de test : Glisser l'extrémité d'un danger mobile redéfinit son axe et sa portée.
Categorie : Unitaire · Path Gesture
Criticite : Bloquant
Etapes :
1. Glisser l'extremite vers le bas (deplacement vertical dominant).
2. Recommencer en glissant vers la gauche, au-dela du depart.
Resultat attendu : Le premier glisser bascule sur l'axe vertical avec la bonne portee ; le second, qui pointerait une portee negative, la ramene a zero – DangerMoverConfig decrit une course dans le sens positif de son axe.

Cas de test : Un geste complet ne produit qu'une seule action finale.
Categorie : Unitaire · Path Gesture
Criticite : Bloquant
Etapes :
1. Amorcer un geste puis enchainer plusieurs mises a jour d'apercu.

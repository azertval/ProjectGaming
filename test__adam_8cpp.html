TEST ( AdamTest ,
AbsenceDeNanSurGradientNulPersistant  )

Sur un gradient nul persistant (paramètre déjà à l'optimum), Adam ne produit ni NaN ni inf, grâce au terme epsilon au dénominateur.

Cas de test : Adam : absence de NaN/inf sur gradient nul persistant.
Categorie : Unitaire · Optim
Criticite : Majeur
Etapes :
1. Construire un paramètre scalaire de gradient toujours nul.
2. Appliquer 50 step consécutifs (gradient remis à zéro entre chaque, déjà nul).
Resultat attendu : value reste fini après chaque pas.

CompteurDePasPartage  )

Deux paramètres distincts optimisés par la même instance d'Adam partagent le même compteur de pas (incrémenté une fois par step, pas une fois par paramètre).

Cas de test : Adam : compteur de pas partagé.
Categorie : Unitaire · Optim
Criticite : Majeur
Etapes :
1. Construire deux paramètres scalaires de même valeur et même gradient.
2. Les optimiser ensemble par la même instance d'Adam, sur trois step.
Resultat attendu : Les deux paramètres restent égaux après chaque pas (même trajectoire, même compteur).

◆ TEST() [4/4]

TEST ( AdamTest ,
CorrectionDeBiaisAuPremierPas  )

Sur le tout premier step (compteur = 1), mHat/vHat correspondent à la formule de correction de biais, pas aux moments bruts.

Cas de test : Adam : correction de biais au premier pas.
Categorie : Unitaire · Optim
Criticite : Critique
Etapes :
1. Construire un paramètre scalaire value = 0, grad = 1.
2. Appliquer un seul Adam(0.1f, 0.9f, 0.999f, 1e-8f).step({parameter}).
Resultat attendu : m = 0.1, v = 0.001, mHat = m/(1-0.9) = 1, vHat = v/(1-0.999) = 1, donc value = 0 - 0.1 * 1/(sqrt(1)+1e-8) ≈ -0.1, distinct de la formule non corrigée (qui donnerait -0.1*0.1/(sqrt(0.001)+1e-8) ≈ -0.316).

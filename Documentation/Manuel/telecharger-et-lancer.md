# Télécharger et lancer le jeu {#manuel-telecharger}

Une version **Debug** du jeu est publiée automatiquement à chaque mise à jour :
elle est **autonome** (aucune installation de Visual Studio requise).

## Prérequis
- **Windows 64 bits** (x64).

## Étapes
1. Ouvrir la page de la dernière version :
   <https://github.com/azertval/ProjectGaming/releases/tag/debug-latest>
2. Dans la section **Assets**, télécharger **`ProjectGaming-debug.zip`**.
3. **Décompresser** l'archive dans un dossier de votre choix (clic droit →
   *Extraire tout…*).
4. Ouvrir le dossier extrait et double-cliquer sur **`ProjectGaming.exe`**.

Une fenêtre de jeu s'ouvre. Pour Quitterter : fermer la fenêtre (croix) ou appuyer
sur **Échap**.

## Remarques
- Cette version « roulante » (`debug-latest`) correspond toujours au **dernier
  état intégré** du projet ; elle est marquée *pre-release*.
- Windows SmartScreen peut afficher un avertissement pour un exécutable non signé :
  *Informations complémentaires* → *Exécuter quand même*.

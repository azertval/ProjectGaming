# Manuel utilisateur {#manuel}

Ce manuel s'adresse aux **utilisateurs** (non-développeurs) : comment récupérer
et lancer le jeu, puis, à terme, comment y jouer.

> À ce stade du projet, le jeu ouvre une fenêtre stable ; le contenu jouable
> (niveaux, mécaniques) arrive dans les lots suivants. Le manuel s'étoffera en
> conséquence.

## Pages

- @subpage manuel-telecharger — récupérer la dernière version et la lancer.
- @subpage manuel-partager-niveau — créer un niveau dans l'éditeur intégré et le partager avec
  l'équipe via Git, sans ligne de commande.

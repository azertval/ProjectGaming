Detailed Description

Tests unitaires de la traduction requête d'écran vers surcharges aisolver-cli (LOT-73, EX-IHM-083).

Ce fichier existe à cause d'un défaut précis : neuf réglages de l'onglet Entraînement étaient lus par l'écran puis jetés, faute de champ où atterrir. Les régler ne changeait rien, et le config.json du run décrivait pourtant un run qui n'avait pas tourné — de sorte que « Reprendre les réglages de ce run » rechargeait des valeurs fausses. Rien n'échouait : ni la compilation, ni un test, ni l'exécution.

Le premier test ci-dessous est écrit pour échouer dans ce cas-là.

TEST ( TrainingOverridesTest ,
LesReglagesSeRetrouventDansLaConfigurationResolue  )

Les surcharges se propagent réellement jusqu'à la configuration résolue : la traduction seule ne prouverait rien si loadTrainingConfig n'en tenait pas compte.

Ce test relie les deux bouts, c'est-à-dire ce que l'utilisateur constate — le run tourne avec ce qu'il a réglé. Cas de test : Les reglages de la requete se retrouvent dans la configuration resolue.
Categorie : Unitaire · Mode IA
Criticite : Bloquant
Etapes :
1. Traduire une requete completement renseignee.
2. Resoudre la configuration sans fichier, avec ces seules surcharges.
Resultat attendu : La configuration porte les valeurs reglees, y compris les neuf communes.

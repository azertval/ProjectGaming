TEST ( HiddenSizeForModelTest ,
ResolueDepuisLeConfigDuRunSinonDefaut  )

La taille de couche cachee d'un modele est relue dans le config.json de son run.

Cas de test : Taille de couche cachee resolue depuis le config.json voisin du modele.
Categorie : Unitaire · AiSolver Cli
Criticite : Bloquant
Etapes :
1. Ecrire un config.json portant une hiddenSize differente du defaut, dans un dossier de run.
2. Appeler hiddenSizeForModel sur le chemin d'un modele de ce dossier.
3. Recommencer sans config.json.
Resultat attendu : La taille du fichier est renvoyee, et le defaut documente lorsque le fichier est absent — sans quoi tout modele entraine avec une autre taille serait irrecuperable.

Detailed Description

Logique du sous-menu « Touches de l'éditeur », indépendante du dessin.

Onze lignes navigables (neuf actions d'éditeur + « Réinitialiser » + « Retour »), même mécanique que GameKeybindingsModel (voir sa doc pour le protocole de capture) — classe séparée plutôt qu'une abstraction commune (décision de cadrage LOT-29 : deux cas concrets connus). La mise en page réutilise telles quelles les constantes de GameKeybindingsModel (TITLE_Y, ROW_SPACING, ROW_SCALE, …), sur le même principe qu'OptionsModel réutilisant MenuModel.

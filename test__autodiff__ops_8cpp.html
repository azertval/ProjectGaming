◆ TEST() [11/20]

TEST ( AutodiffOpsTest ,
LogOpPlancheLeZeroEtRefuseUneEntreeNegative  )

logOp refuse une entrée négative (erreur de programmation), mais accepte un zéro numérique, qu'elle planche.

La distinction n'est pas cosmétique : l'appelant réel est la perte de policy gradient, dont l'entrée est une probabilité de softmax. Une politique qui se spécialise produit des probabilités qui s'annulent en flottant — ce n'est pas un bug de l'appelant, c'est l'arithmétique. Assertionner sur ce zéro faisait échouer l'entraînement en Debug et propageait -inf en Release ; un logarithme d'un nombre négatif, lui, reste une erreur de programmation. Cas de test : Ops : logOp planche un zéro et refuse une entrée négative.
Categorie : Unitaire · Autodiff
Criticite : Majeur
Etapes :
1. Appeler logOp() sur une feuille contenant 0.0f.
2. Appeler logOp() sur une feuille contenant une valeur négative.
Resultat attendu : Le zéro produit une valeur finie sans déclencher d'assertion ; la valeur négative déclenche le gestionnaire d'assertion.

Detailed Description

Test de non-régression du volume de primitives et de l'efficacité du culling (LOT-62 TACHE-01, EX-NFR-005, EX-NFR-004).

CalqueComposeDeuxFoisDepasseLePlafond  )

Émettre accidentellement un calque en double fait dépasser le plafond du niveau : le contrôle est sensible, pas simplement très large.

Cas de test : Composer un calque deux fois depasse le plafond du niveau.
Categorie : Unitaire · Budget de rendu
Criticite : Critique
Etapes :
1. Composer normalement demo-deplacement en mode Texture.
2. Composer une seconde fois dans la meme scene (double emission).
Resultat attendu : Le volume double depasse le plafond nomme du niveau, alors que la composition simple restait dessous.

Sur un grand niveau à plusieurs salles, le culling écarte une fraction significative des primitives : c'est ce qui distingue un culling qui fonctionne d'un culling qui compile.

Cas de test : Le culling ecarte une fraction significative sur un grand niveau.
Categorie : Unitaire · Budget de rendu
Criticite : Critique
Etapes :
1. Charger demo-salles (plusieurs salles).
2. Composer sa scene sur la salle d'entree, en mode Texture.
Resultat attendu : Au moins la moitie des primitives examinees sont ecartees par le culling.

DeuxCompositionsDeLaMemeSceneDonnentLeMemeVolume  )

Le volume de primitives d'une scène est déterministe : composer deux fois la même scène, avec la même caméra, donne exactement les mêmes compteurs.

Cas de test : Deux compositions de la meme scene donnent le meme volume.
Categorie : Unitaire · Budget de rendu
Criticite : Majeur
Etapes :
1. Composer deux fois la scene de demo-salles, en mode Texture.
Resultat attendu : Les compteurs (examinees, ecartees, soumises, passes) sont strictement identiques.

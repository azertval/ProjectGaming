TEST ( SgdTest ,
MiseAJourAvecInertie  )

Avec inertie, la vitesse s'accumule sur deux step consécutifs à gradient constant, selon vitesse = momentum * vitesse - learningRate * grad.

Cas de test : Sgd : mise à jour avec inertie.
Categorie : Unitaire · Optim
Criticite : Critique
Etapes :
1. Construire un paramètre scalaire value = 0, grad = 1 constant.
2. Appliquer Sgd(0.1f, 0.9f).step({parameter}) deux fois de suite (gradient reposé à 1 entre les deux).
Resultat attendu : Après le premier pas, vitesse = -0.1, value = -0.1. Après le second, vitesse = 0.9*(-0.1) - 0.1 = -0.19, value = -0.1 - 0.19 = -0.29.

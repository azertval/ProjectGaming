◆ slopeTileGridPosition()

std::optional< AtlasGridPosition > hmi::slopeTileGridPosition ( core::TileType  type)

Position, dans la grille de tuiles procédurale, réservée à un type de tuile à silhouette inclinée/courbe : pentes/arrondis convexes ou concaves de sol, suivables (core::isFollowableSurface, EX-GP-003/EX-GP-004/EX-GP-007) ou de plafond, solides (EX-GP-006/EX-GP-007).

Parameters
typeType de tuile.
Returns
La position dans la grille, ou std::nullopt si type n'a pas de silhouette inclinée/ courbe.

◆ toPlayerInput()

core::PlayerInput hmi::toPlayerInput ( const InputState &  input,
const GameKeyBindings &  gameKeyBindings,
const GamepadBindings &  gamepadBindings 
)

Traduit l'état d'entrée en core::PlayerInput, dissocié des touches/boutons physiques (EX-CTRL-010, EX-CTRL-012).

Le reste du moteur ne connaît que l'intention (moveX), pas les touches ni les boutons. Chaque action est déclenchée par deux sources indépendantes, chacune remappable séparément : la touche clavier liée dans gameKeyBindings (Options → Touches de jeu) ou le bouton manette lié dans gamepadBindings (Options → Touches de la manette) — l'une des deux suffit, aucune des deux n'est prioritaire sur l'autre.

Gauche et droite simultanées se neutralisent (moveX == 0). Fonction pure, testable avec un InputState injecté (EX-NFR-010) ; appelée une fois par frame en amont de la logique (EX-CTRL-020, EX-CTRL-021).

Parameters

Detailed Description

Fenêtre native (QWindow) où Direct3D 11 présente, embarquée dans Qt.

Mode édition (LOT-35) : affiche le brouillon (core::LevelDraft) via hmi::DraftRenderer, caméra cadrant le niveau entier. Le clic/glisser gauche peint le type de tuile actif (setActiveTile, fourni par la palette) à la case survolée (core::LevelDraft::paintTile) ; Ctrl+Z/Ctrl+Y annulent/refont. Mode essai (LOT-35 TACHE-04) : une hmi::GameSession rejoue le niveau ; sa boucle à pas fixe (core::FixedTimestep) et ses entrées (Qt + XInput) reprennent la discipline du LOT-33.
